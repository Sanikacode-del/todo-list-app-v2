# To-Do List App 📝

This is a simple frontend To-Do List app built using *HTML, **CSS, and **JavaScript*.

## 🚀 Features
- Add tasks
- View task list instantly
- Easy to use

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript

## 🖥 How to Run
1. Go to the frontend folder
2. Open index.html in your browser

## 💡 Future Plans
- Add backend using Node.js
